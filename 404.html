Agents & CLI

Private payments for agents too.

An agent that pays for APIs or data leaves a public trail of everything it buys. With Lumwatch it pays from a private balance, from a script or over MCP.

  • Proofs on your device · keys never leave the machine
  • Relayer pays gas · the agent wallet never touches the payment
  • MCP server · planned, so any agent host can call it






  
How it works
Four steps, no trail.
The design Lumwatch is being built on. Contracts will be published and verified on Sourcify before anything goes live.

  

    
1ShieldYour deposit becomes a sealed note in a shared pool.

    
2ProveYour browser proves you own a note, without saying which one.

    
3RelayA relayer submits the payment and pays the gas.

    
4DeliverThe recipient gets plain USDG. Nothing links the two sides.

  

  
The difference
Private is not the same as hidden from the rules.
Anyone can prove their funds are not from a public list of hacks or sanctioned addresses, without revealing their own history. Privacy for you, a clear answer for whoever asks.






  
FAQ
Before you set sail.

  

    
Can I use private payments today?
Not yet. Shield, Private send and Clean proof are in development. The app above is a walkthrough with example numbers. The token check is the only part that is live.

    
Is this a mixer?
It is a privacy pool with a clean proof built in. You can prove your funds are not from a public block list of hacks and sanctioned addresses, without showing which deposit is yours.

    
Does Lumwatch hold my funds?
No. The pool is a contract and only your key can open your notes. There is no admin who can move them.

    
Which chain and tokens?
Robinhood Chain first, with USDG and ETH. Other chains come later.

    
When will it launch?
When the contracts are written, audited, verified on Sourcify and tested on mainnet. The log below shows where each piece stands.

    
Is there a token?
If there is one, its contract address will be posted here and on our X account first. Anything else using the Lumwatch name is not us.
